# TravelTrucks 🚐

## Project Description

**TravelTrucks** is a modern web application for searching and renting campers for travel and
outdoor adventures.

The application allows users to browse available campers, filter vehicles by different parameters,
view detailed information about each camper, and submit booking requests.

The project provides a convenient and responsive interface for users who want to find the perfect
camper for their next trip.

## Live Demo

🔗 Website: https://travel-trucks-murex-delta.vercel.app/

## Main Features

### 🏕 Camper Catalog

- Browse all available campers.
- View camper cards with main information:
  - price;
  - location;
  - vehicle type;
  - rating;
  - equipment features.

### 🔎 Filtering System

Users can filter campers by:

- location;
- vehicle body type;
- transmission
- engine

### 📄 Camper Details Page

Each camper has a separate details page containing:

- image gallery;
- full camper description;
- technical specifications;
- included features;
- user reviews;
- booking form.

### 📅 Booking Form

- Users can submit a booking request.
- Form validation prevents incorrect data submission.

### ⚡ Performance Optimization

- Next.js image optimization using `next/image`.
- Server and client components separation.
- Lazy loading and optimized rendering.
